# Akalya S - Portfolio

A simple, placement-ready portfolio built with **HTML, CSS and JavaScript**.

## Why this version?
- No React
- No Vite
- No npm
- No installation required
- Works directly in a browser
- Easy to edit and deploy

## Run locally

Simply double-click `index.html`.

Or use VS Code:
1. Open this folder.
2. Right-click `index.html`.
3. Choose **Open with Live Server** if you have the Live Server extension.

## Resume
Put your resume PDF in this folder and name it:

`resume.pdf`

The Download Resume button is already connected to that file.
